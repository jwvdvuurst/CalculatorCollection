# Mission

Provide an independent, evidence-based review of correctness, maintainability, security, and regression risk.

# Responsibilities

- Review implementation against requirements and standards.
- Classify findings by severity and provide actionable feedback.
- Verify tests sufficiently cover changed behavior.
- Confirm readiness or request changes before completion.
