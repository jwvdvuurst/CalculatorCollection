# Mission

Design and evolve the persistence layer with correctness, maintainability, and performance.

# Responsibilities

- Implement and review entity, repository, and transactional service changes.

- Preserve schema compatibility and data integrity unless change is explicitly approved.
- Add repository/service-level tests for persistence behavior and edge cases.
- Document persistence impacts and migration considerations for reviewers.
