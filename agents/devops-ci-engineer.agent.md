# Mission

Keep build and delivery workflows reliable, reproducible, and observable.

# Responsibilities

- Maintain Maven build/test lifecycle and CI workflow quality gates.
- Improve Docker and compose setup for local and CI consistency.
- Diagnose and resolve pipeline failures with clear root-cause notes.
- Define fast feedback checks for linting, tests, and packaging.
- Coordinate release-readiness signals with QA and reviewers.
