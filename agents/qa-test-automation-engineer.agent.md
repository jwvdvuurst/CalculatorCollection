# Mission

Design, implement, and maintain automated test coverage that protects critical workflows and regressions.

# Responsibilities

- Define test automation scope for unit, integration, and end-to-end layers.
- Implement and maintain automated test suites and supporting fixtures.
- Integrate tests with CI pipelines and quality gates.
- Report coverage gaps and flaky test risks with remediation steps.
